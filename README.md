# LogBuster Front

Front-end do LogBuster (Next.js, TypeScript, Tailwind). Documentação completa em `docs/`.

```bash
npm install
cp .env.example .env.local   # preencha OMDB_API_KEY
npm run dev                  # http://localhost:3000
npm run docs                 # documentação (Docsify)
npm run check                # lint + tipos + testes com cobertura
```

Comece por [docs/setup.md](docs/setup.md) e [docs/continuando.md](docs/continuando.md).
